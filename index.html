Key Capabilities / 核心特色

🛡️

企業級資安與零數據留存
Zero Data Retention (ZDR)

所有履歷解析與文件生成完全於伺服器記憶體內（RAM）運算完成，絕不寫入任何資料庫或硬碟快取，會話結束即刻徹底銷毀。
100% in-memory architecture guaranteeing no candidate PII persistence on storage systems.

🧹

智慧單字重組與 OCR 雜訊清洗
Smart Word & Character Repair

自動修復 PDF/OCR 複製失真導致被空格拆散的英文單字與姓名（例如將被拆散的 C h a n T a i M a n 復原為 Chan Tai Man [陳大文]、M o b i l e 復原為 Mobile），並過濾特殊亂碼圖示與獨立頁碼雜訊。
Automatically repairs broken English words and names caused by OCR/PDF copy-paste issues.

📱

手機端友善與雙格式匯出
Mobile-First UI & Dual Export

採用 st.tabs 頁籤設計，手機操作無須漫長滑動。支援自動對齊大標題、自動提取人名命名檔案，並可一鍵下載 Word (.docx) 與 PDF (.pdf)。
Features tab-based responsive navigation, automatic candidate file naming, and dual DOCX/PDF downloads.

🛡️ Zero Data Retention (ZDR) 隱私與資安保護架構

🔒 100% 記憶體即時運算 (In-Memory Processing)

所有履歷文字解析與文件生成完全在伺服器 RAM 內存完成，絕不安裝或寫入任何資料庫或硬碟快取。
All formatting is performed strictly in memory. No database storage or persistent file retention.

🔒 PII 個資零留存 (Privacy-by-Design)

使用者貼入之求職者聯絡資料、工作經歷等敏感資訊（PII），在會話（Session）關閉後即刻自動銷毀，完全保障求職者隱私。
Candidate PII is never logged or exposed, conforming to privacy-by-design standards.
